## 三、过程中发现并解决的问题

1. Gradle 构建挂起：`gradle-daemon-jvm.properties` 自动生成为 JDK 25，本机无此版本导致联网下载阻塞——改为 17 后恢复。
2. 模拟器 Quickboot 快照回滚（两次造成影响）：加载旧快照会把虚拟机连磁盘一起回滚，曾导致已装新版本与测试数据"凭空消失"、用户在 AS 中看不到新功能。处置：删除快照缓存（已授权）、开发期无界面会话一律 `-no-snapshot`、已建议用户将 AS 设备启动选项设为 Cold Boot。
3. LazyColumn key 冲突：饮食/运动两列表使用相同 id 序列作 key，进记录页即闪退——加前缀修复。
4. FAB 遮挡：列表滚到底时末尾卡片的删除按钮被悬浮按钮挡住——列表底部留白修复。
5. Compose 典型错误两起：`stringResource` 在点击回调中调用（提升到组合作用域）、字符串资源重名（资源打包失败）。
