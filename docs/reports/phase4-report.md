## 二、关键设计决策

| 决策 | 理由 |
|---|---|
| HTTP 用平台 HttpURLConnection，不引 OkHttp | 每天仅一次请求，零新依赖避开国内镜像拉取坑；OpenAI 兼容格式简单，手写足够 |
| 「成功才记账」水位线 | 欠费/断网/超时/格式异常全部自然形成缺口、次日合并补交——不为任何失败类别写专门逻辑 |
| 概要程序算、明细字段瘦身 | token 成本恒定（增量约每天 700）、隐私面最小、模式统计不出错 |
| 首份报告带近 30 天明细 | 建议必须建立在「平时的你」上，避免单日数据小题大做 |
| API Key 三条红线（仅存本机/不入备份/只发所填地址） | 用户安全底线；备份导出实测全文搜不到 Key，「本次发送的数据」入口可逐字核验 |
| 报告「先做什么再为什么」+ 折叠详情 | 真机验收反馈：篇幅长难抓重点；行动摘要常显一屏扫完，依据与细节按需展开 |
| 无状态请求（无服务商会话记忆） | 换模型商/换模型零成本，中断恢复不依赖可能过期的会话 |

## 四、过程中遇到并解决的问题

1. **API 37 模拟器应用访问 10.0.2.2 卡死 SYN-SENT**（env-pitfalls #23）：Android 应用 socket 均为 v4-mapped IPv6，该模拟器 QEMU 不做 NAT；改 `adb reverse` + 应用填 127.0.0.1 解决，网络安全配置明文放行清单同步补 127.0.0.1。
2. **HyperOS 真机禁止 adb 注入输入**（#24）：普通 USB 调试下 `input tap/swipe` 抛 SecurityException；真机验收改「用户操作 + adb 只读核验（screencap/uiautomator dump）」分工模式，未去开需小米账号的「USB 调试（安全设置）」。
3. **uiautomator dump 的节点级陈旧缓存**（#14 补充）：状态文本已渲染但 dump 读不到，曾误判 401 提示未显示；断言动态文本两次不中即改截图核验。
4. **Mimosa 安全 hook 两次拦截**：遗留脚本 `ui.py` 动态路径写文件被判路径穿越高危——先改临时目录仍拦（针对「open(变量路径写)」模式本身），最终去掉本地文件、adb stdout 直读内存通过；期间三次提交 hook 均提示「扫描结论不完整（python_ast/callgraph 部分不可用）按兼容策略放行」，已如实记录，建议后续重跑完整审计。
