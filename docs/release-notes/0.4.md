## 0.4.0（2026-10-24 · versionCode 8）AI 生活建议：接口接入与每日报告

### 用户可见的新增

- **AI 接口配置**（设置 → AI 接口）：OpenAI 兼容三要素（接口地址 / API Key / 模型名），智谱、DeepSeek、OpenAI 等主流服务商通用；「测试连接」一键验证；Key 掩码显示
- **每日 AI 营养报告**：每天凌晨 4:00 自动汇总前一天的饮食（含营养品成分明细）与运动，生成结构化报告（总评 / 建议 / 饮食分析 / 运动分析），早晨无声通知查看；报告滚动保留 14 天；「立即生成」随时手动补看
- **建议的呈现方式**：每条建议一行**行动摘要**常显（如「餐后吃橙子猕猴桃补维C」），点「展开详情」查看执行细节与依据（你的数据事实 + 膳食指南推荐量）；涉及营养缺口时同时给食物来源与营养品选择（剂型、参考剂量，以产品说明或医嘱为准）；「提醒」级建议整卡警示色，总评大字卡置顶——重点一眼可辨
- **中断自动补交**：欠费 / 断网 / 超时导致的失败不丢进度，服务恢复后自动合并生成「回顾报告」追平
- **隐私自查入口**：每份报告详情底部可展开「本次发送的数据」（逐字核验发了什么，没有任何密钥）与「原始返回」（AI 回复原文）；API Key 仅存本机、不随备份导出、只发送到你填写的这一个地址

### 用户可见的修复

- 无（本版为纯新增功能版本）

关键设计决策（详见 [code/ai-layer.md](../code/ai-layer.md)）：

- **成功才记账水位线**：所有失败类别殊途同归为「缺口」，次日合并补交，零专门逻辑
- **概要程序算、明细瘦身**：token 成本恒定（约每天 700）、隐私面最小
- **首份报告带 30 天明细**：建议建立在「平时的你」上
- **无状态请求**：不依赖服务商会话记忆，换模型商零成本

验证汇总：模拟器全链路（迁移 / 五错误场景 / 三生成模式 / 闹钟链路 / 自愈 / 备份无 Key）+ 真机实测（配置、真实报告、格式迭代复验）均通过，过夜自动报告验收见 [phase4 报告](../reports/phase4-report.md)第三节。
