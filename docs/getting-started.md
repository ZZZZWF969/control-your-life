# 新手上手指南

> 写给第一次安装「每日掌控」的你：十分钟走完一遍，就知道它每天会为你做什么。
> 这个应用**没有账号、不上传任何东西**，所有数据只存在你手机里（唯一的网络出口是你自己配置的 AI 接口，见第五节）。

## 一、首次打开：一分钟权限向导

第一次启动会出现 5 步引导（每步都有说明，可随时跳过）：

1. **欢迎**——应用是干什么的
2. **通知权限**——所有提醒靠通知，这步必须允许，否则应用是哑巴
3. **精确闹钟**——保证提醒准点（差几分钟都可能误事）；点「去系统页授权」→ 找到「每日掌控」打开「闹钟和提醒」开关 → 返回应用点「重新检测」
4. **HyperOS 渠道三件套**——小米/红米手机专属：系统对每个通知渠道单独设开关，按引导把「允许通知 + 悬浮通知 + 锁屏显示」逐渠道打开；可发条测试通知自查
5. **自启动与电池**——把省电策略设为「无限制」并允许自启动，否则后台提醒会被系统冻结

> 向导没做好也没关系：设置页有「重新查看权限引导」，随时重来。

## 二、记下第一笔（1 分钟）

底栏「今日」页 → 右下角圆形 **「记一笔」** 按钮：

- **记饮食**：选餐别（会按当前时间智能预选）→ 填食材（如「米饭、青椒炒肉」）→ 饭量三选一 → 保存
- **记运动**：选类型（跑步/骑行/力量/球类/自定义）→ 起止时间默认「过去半小时到现在」，通常不用改 → 填总量（如 5km）→ 保存
- **营养品**：餐别选「营养品」→ 填品名与净含量 → 点「添加成分」逐行录入（如 VA 800μg、钙 300mg）——这些结构化成分是将来 AI 营养分析的重要原料

全程不跳页，存完直接出现在今日列表里。点任何一条记录可以直接编辑。

## 三、提醒会自己来（不用你设闹钟）

只要权限配好了，以下提醒全自动：

| 什么时候 | 会发生什么 | 你要做什么 |
|---|---|---|
| 饭点后（早 9:30 / 午 13:30 / 晚 19:30，可改） | 询问「这餐记了吗」 | 点通知直达该餐的预填表单，30 秒记完；已记过则不打扰 |
| 白天 10:00–23:00 | 循环提醒背单词（每 1.5 小时一次） | 点通知跳去背单词应用；背完回应用点「今日已背」，当天不再提醒 |
| 每晚 22:00 | 提醒规划明天 | 见下一节 |

## 四、睡前规划 + 起床双保险（1 分钟/晚）

今日页点「去规划今天 / 明天」：

1. **待办**：加明天要做的事，可选开始时间与提前提醒量；不设时间也行（纯记录）
2. **起床闹钟**：明早有课就选「早八」或「早十」，没课选「无课」
3. 保存后会弹出**「去时钟开一个闹钟」**的引导——请按建议时刻在系统时钟里手动开一个闹钟

> 为什么不替你自动开？安卓公开接口**读不到也删不掉**时钟里已有的闹钟，自动开只会越积越多。所以方案是「双保险」：**系统时钟的铃声做叫醒主力**（走闹钟音量，静音也响），**应用在同一时刻发持续震动做保底**（渐进 4 声，末声震动到把你处理掉为止）。

## 五、（可选）开启 AI 每日营养报告

需要一个 OpenAI 兼容服务的账号（智谱 GLM、DeepSeek、OpenAI 等均可，有免费或低价档）：

1. 设置 → **AI 接口**：填接口地址、API Key（在该服务商控制台创建）、模型名——以 DeepSeek 为例：`https://api.deepseek.com/v1` + `deepseek-chat`
2. 点 **测试连接** → 绿色「连接成功」即可
3. 之后**每天凌晨 4:00 自动**汇总你前一天的饮食与运动，生成营养建议报告，早晨无声通知你查看——每条建议先告诉你「做什么」（如「餐后吃橙子猕猴桃补维C」），想看细节再展开「依据」

**隐私边界**（应用里都能亲手核验）：

- 数据全部只在本地；发给 AI 的只有饮食/运动汇总，**报告详情页可展开「本次发送的数据」逐字查看**
- API Key 只存你手机（卸载即清除）、**不写入任何备份文件**、只发送到你填写的这一个地址
- 中断不怕：欠费/断网后服务恢复，应用会自动补交缺失日期的「回顾报告」

## 六、数据备份（不用操心）

- **每周自动**：应用自动把全部数据写成 JSON 存进手机「下载」目录（滚动保留 4 份，卸载应用也不会删）
- **手动随身**：设置 → 备份与恢复 → 导出全部数据，存到网盘或发给自己
- **换机/重装**：新机装好应用 → 从备份恢复 → 全部数据与设置回填

## 常见问题

| 现象 | 处理 |
|---|---|
| 提醒不响 / 时候不准 | 九成是权限：通知权限、精确闹钟、电池「无限制」、自启动——设置页可重看引导逐项检查 |
| 锁屏看不到通知 | HyperOS 需按「渠道」逐个开三件套（引导第 4 步有路径） |
| AI 报告生成失败 | 通知/状态卡会写明原因（Key 无效、余额不足、超时）；恢复后自动补交，无需处理 |
| 想换 AI 服务商 | 设置里改地址/Key/模型名即可，历史报告保留 |
