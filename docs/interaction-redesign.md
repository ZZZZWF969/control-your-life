## 二、今日页新布局（用户描述的确认版）

自上而下：

1. **问候 + 日期**：保持现状（时段问候语）。
2. **小结卡**：三餐完成度徽标 + 运动总时长，保持现状。
3. **今日饮食列表**：保持现有精简行样式（徽标+内容+时间）；改动两点——
   - 列表超过 6 条时末尾显示「查看全部（N 条）」跳记录页（默认决策，可否决）；
   - **行可点，点击直接弹出编辑表单**（用户确认），今日页自成闭环，改一条数据不跳页。
4. **今日运动列表**：同上。
5. **背单词状态卡**：极简版（2026-10-19 用户补充确认）——**一句话状态**（「今天还没背单词」/「今天已背单词 ✓」）+「今日已背」记录按钮（已背后隐藏）+「去背单词」跳转按钮（已配包名时显示）；不带任何频率说明文案（旧文案「每 1.5 小时提醒一次（至 23:00）」已删，实际循环逻辑不变）。
6. **今日待办清单**：从提醒页搬迁，交互增强——
   - 未完成在上（按开始时间排）、**已完成打勾、颜色调浅、沉到列表底部**（用户确认：已完成也显示，不消失）；
   - 勾选 = 完成（撤该任务闹钟）；**反勾 = 恢复**：若提醒时刻仍在未来则重排闹钟，已过则提示「提醒时刻已过，不再补排」（勾选闹钟丢失修复，一并修项）；
   - 删除带二次确认（现状逻辑保持）；
   - 无待办时显示空状态引导（文案 + 「去规划」按钮）。
7. **底部入口区**：「去规划」按钮（常驻）；「去时钟开闹钟」按钮（明天有唤醒计划且未自记确认时显示，点「闹钟已开 ✓」收起——逻辑原样搬迁）。
8. **悬浮「记一笔」按钮**（用户确认形态）：点击 → 弹饮食/运动两卡片类型选择（与记录页现有弹层完全一致）→ 弹对应表单，**全程不离开今日页**；保存直接落库，列表即时刷新（Flow 订阅已天然支持）。

**空状态**：饮食/运动/待办各区为空时给引导文案；今日页整体不再有「按钮条件消失」的情况（旧稿 P1-1 问题随整合自然消解）。

### 实现要点（工程结构）

- `DietEntrySheet` / `ExerciseEntrySheet` 本就是独立组件，今日页直接挂载；**保存落库逻辑（事务写入、新建/编辑分支）与记录页完全相同，抽成公共函数两页复用**（低耦合规范，避免复制粘贴两份事务代码）。
- 待办行组件（现 RemindScreen 内的 `TodoTaskRow`）随迁移挪为今日页的子组件；今日页内容量增大，按「页面主文件 + 子组件文件」组织，避免单文件膨胀。
- 已完成沉底排序在界面层做（数据库不存排序字段，未完成按开始时间、已完成按完成先后），不動表结构。
- 深链进今日页弹表单的机制复用现有 `record?meal=` 参数模式，今日页如法支持（背单词通知等落点切换时保持体验一致）。

## 四、设置页重排（用户确认：分组 + 调试折叠）

分组顺序与形态：

1. **外观**：主题三档（现状）
2. **提醒时刻**：三餐 + 晚间规划四行时间（含第 5 条整行可点改造）
3. **跳转应用**：背单词包名输入（现状）
4. **数据备份**：最近备份时间 + 导出/恢复按钮（现状）+ 权限引导入口（见批次 4，落地时加入「重新查看引导」）
5. **调试工具**（折叠区，默认收起）：精确闹钟授权提示、发测试通知、建测试待办、模拟各提醒、数据库自检——验收与排查时手动展开，日常不可见

折叠区实现：卡片标题行可点 + 展开动画（`animateContentSize`，Compose 官方动画 API），无第三方依赖。
