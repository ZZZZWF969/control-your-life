# 待办与远景规划

> 需求与决策的总依据是根目录 [goal.md](../goal.md)（含用户原话记录与逐条确认的决策），本文是面向访客的路线图视图。
> 状态分三档：**下一步**（确定即将开始）→ **待办池**（有共识、排期待定）→ **远景规划**（方向性想法，方案未定）。

## 下一步（确定即将开始）

- **AI 追问机制（0.4.1）**：AI 对不完整的信息（如身高体重、饮食目标、昨晚睡眠）主动向你提问，问题呈现在应用内；你的回答作为补充提示词随次日数据一并提交，不阻塞当日报告。0.4.0 已预留好接口：报告表的 `questionsJson` 字段、提示词 schema 的 `questions` 约定、mock 服务的场景开关。
- **报告质量持续调优**：真机日常使用中观察建议的具体度与营养品指引质量，按 [code/ai-layer.md](code/ai-layer.md) 的提示词定制指引调参（无需改代码结构）。

## 待办池（有共识、排期待定）

- **NRV 包装食品营养成分表录入**：针对有净含量标注的包装食品，录入包装上的营养成分表（NRV）与单份净含量，换算实际摄入量——为 AI 营养分析提供更精确的数据（与营养素结构化子表衔接）。
- **UI 精修专项**：骨架期保持克制的默认风格；待 AI 主链路完成后设专门批次统一精修（视觉层次、图标系统、空状态、动效、字体），届时出多版设计变体供选择。
- **起床唤醒增强（备选方案）**：①「保底闹钟」开关——可选把末声同时写入系统时钟（接受每日 1 条积累，标签带日期）；②锁屏全屏响铃界面（Android 14+ 对非闹钟类应用默认拒绝，需评估）；③ 渐进声数可配置（当前固定 4 声）。
- **Room 迁移自动化测试**：数据库升级路径（1→2→…）的迁移测试纳入构建，替代目前的人工验证。
- **CI（GitHub Actions 自动构建）**：push / PR 自动跑 `assembleDebug`，给贡献者的 PR 挂构建结果徽章；环境自检脚本的 0/1 退出码已为接入预留。**等仓库彻底成形后再上线**（2026-10-24 商定）。
- **issue / PR 模板与贡献指南**：bug 模板要求贴 `script/check-env` 自检输出便于排障，PR 模板对齐提交规范。**同上，仓库彻底成形后上线**（2026-10-24 商定）。

## 远景规划

- **药箱管理**：家中药箱——药物与常备器械的过期时间、是否 OTC、余量、按日常用途（抗过敏 / 感冒 / 止痛 / 紧急止血等）检索；概况卡片 + 详情页两级展示。
- **睡眠记录 / 运动自动同步**：优先走安卓官方的 Health Connect 通道，可读取小米手环 / 手表及运动 App 的数据——解决「入睡时间无法可靠记录」的老问题。
- **课程表导入智能起床**：导入课表后自动分析明天早上应该几点起，替代手动勾选「早八 / 早十」。
- **闹钟区间随机起闹（时钟侧）**：应用内渐进震动已支持随机间隔；远景是引导用户在系统时钟实现同款体验。
